This is an unpacked chrome extension that adds a keyboard shortcut (default Ctrl+M) to change the "font" of typed text (using unicode characters for bold, fixed-width, etc text, allowing "fonts" to be applied in textboxes that normally do not allow them). You can select text then apply a "font", or apply a "font" to all typed text. Use Ctrl+Shift+M to reset text / selected font.
To load, download all files, then go to chrome://extensions, select "Load Unpacked", and select the folder containing all files.

All files here were vibecoded (so that I could practice using AI agents in coding).
